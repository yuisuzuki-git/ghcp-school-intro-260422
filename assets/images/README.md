# Image Placeholders and Replacement Guide

This project currently uses gradient-based placeholders so the site can ship before final assets arrive.
Replace the files below in this folder when production images are ready.

- `hero-placeholder.jpg`: recommended 1600x900, used for hero visuals if needed later.
- `campus-placeholder.jpg`: recommended 1600x1000, used for campus/life section.
- `news-placeholder.jpg`: recommended 1200x800, optional news card thumbnails.
- `ogp-placeholder.jpg`: recommended 1200x630, used by Open Graph and Twitter Card meta.

Notes:
- Keep file names stable to avoid HTML edits.
- Optimize image sizes for web delivery (prefer WebP/JPEG under 300KB when possible).
- Add meaningful alt text in HTML when placeholders are replaced with real images.
